# Dubai Property Analytics

Pipeline and analysis of Dubai real estate transactions from DLD Open Data.

## Stack
Python 3.13 · uv · PostgreSQL (Docker) · pytest · Ruff

## Roadmap

- [ ] DLD Open Data → PostgreSQL ingestion + tests
- [ ] EDA
- [ ] Price modeling
